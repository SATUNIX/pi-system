# Report Export Review

Use this skill before producing external deliverables.

- Confirm every finding has evidence IDs, affected assets, impact, severity rationale, remediation, and limitations.
- Remove unsupported claims and raw sensitive data.
- Check that proof-of-concept details fit the ROE and data handling rules.
- Confirm false-positive checks are documented.
- Mark unresolved hypotheses as out of report scope unless the operator asks for an appendix.
