## Is a page stale?

List the commits since the page's commit that touched its code:

```sh
git log --oneline <commit>..HEAD -- packages/extensions/src/tool-firewall
```

If any of them change behaviour, regenerate the page. Changes since a page's commit that are
known to matter:

- **Subagents** (`b82d285`): children now inherit the firewall's root session through
  `PI_KIT_FIREWALL_ROOT_SESSION` when `PI_KIT_INTERNAL_CHILD=1`, so session allows are shared
  (`e0b540d`).
- **Profiles** (`b82d285`): every profile now also enables `tool-capture` (`399b221`).
- **Tool firewall** (`bc0ec11`): reads of the capture directory are credential reads, and
  audit records carry `toolCallId` (`399b221`).
